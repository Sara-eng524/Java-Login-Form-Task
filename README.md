# Java Login Form Task

A simple Java AWT login form.

## Features
- Empty-field validation
- Username and password verification
- Role verification
- Login disabled after three incorrect passwords
- Welcome page

## Test Accounts
- student1 / stu123 / Student
- ta1 / ta123 / TA
- prof1 / prof123 / Professor

## Run
Compile: javac -encoding UTF-8 LoginFormTask.java
Run: java LoginFormTask
